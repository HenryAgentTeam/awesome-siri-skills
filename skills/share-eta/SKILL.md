# Share my arrival time

Use the Share ETA tool to share the user's estimated arrival time with the person they named. If the user did not name a person, ask who should receive it before sharing.

When the arrival time is shared, tell the user who received it and what time was shared. If the destination is unclear, ask where the user is headed before sharing.

## Don't

- Don't share the user's live location; share only the arrival time.
- Don't plan a route or give directions; that is a different skill.
- Don't share an arrival time with someone the user did not name.
