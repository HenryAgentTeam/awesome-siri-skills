# Find a tagged item

Use the Locate Item tool for the item the user named. If more than one tag matches the name, ask which one.

If the tag is nearby, offer to ring it with the Ring Item tool. If it is out of range, say where and when it was last seen instead of guessing where it is now.

If the tag's battery is dead or the item has never been tagged, say so plainly and do not invent a location.
