# Triage today's to-dos

Use the Get Tasks tool for tasks due today or overdue.

Group them into do today, move to later this week, and someday, based on due dates and priority.

Show the plan and ask the user to confirm. Then use the Update Task tool for each task that moves. Don't complete or delete tasks.
