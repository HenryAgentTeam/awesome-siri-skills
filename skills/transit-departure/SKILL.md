# Next departures

Use the Get Departures tool to list the next buses or trains leaving from the stop the user named. If they named a line, filter to that line first.

Tell the user the next two or three departures with their line names and times. If nothing leaves soon, say when the next one goes.

## Don't

- Don't buy tickets or plan a full route.
