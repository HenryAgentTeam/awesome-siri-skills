# Check the pollen count

Use the Get Pollen Count tool for the user's area and today, or the day they named.

Use the Get Allergy Advice tool to turn the count into one clear step — take medicine before going out, keep windows shut, or shower after coming back inside.

Tell the user the pollen level in one short sentence, then the one thing that matters most for them today. Don't list every allergy tip.
