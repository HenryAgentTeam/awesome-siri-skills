# Set the house up on arrival

Use the Unlock Door tool to open the front door. Then use the Turn On Lights tool for the rooms the user usually uses first, and the Set Temperature tool to bring the house to the usual comfort level.

If the user names a room, only set up that room. If they say they are only stopping by, unlock the door and skip the lights and temperature.

## Don't

- Don't lock the door or turn things off when the user is arriving.
- Don't change the temperature to a value the user did not ask for.
