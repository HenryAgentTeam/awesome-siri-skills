# Order the usual coffee

Use the Get Favorite Drinks tool. If there is more than one favorite, ask which one.

Use the Find Stores tool for open stores near the user and pick the closest unless they named one.

Tell the user the drink, store and pickup time, and ask them to confirm before using the Place Pickup Order tool.
