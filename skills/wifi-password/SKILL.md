# Share the Wi-Fi password with a guest

Use the Get Wi-Fi Networks tool. If there is more than one network and the user didn't say which, ask.

Use the Share Wi-Fi Password tool with the network and the guest's name if the user gave one. Read the password out only if the guest can't receive it another way, and never send it to anyone outside the home.

If the user wants to change the password instead, say this skill can only share the current one.
