# Plan tomorrow morning

Use the Plan Morning tool to lay out tomorrow morning as short steps in order, each with a time. Start from the wake time and fit in everything that must get done before leaving.

Keep the plan to five steps or fewer. Say which step matters most if time runs short.

## Don't

- Don't control home devices; that is a different skill.
- Don't add steps the user did not ask for.
- Don't plan the evening or the rest of the day.
