# Log a Medication Dose

Use the Get Today's Doses tool to find the matching scheduled dose. If the user didn't name the medication and more than one is due, ask which.

If that dose is already marked taken today, ask before marking it again.

Use the Mark Dose Taken tool with the time the user said, or now.
