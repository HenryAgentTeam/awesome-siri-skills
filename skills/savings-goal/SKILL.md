# Savings goal progress

Use the Get Savings Goal tool for the named goal at the user's bank.

Give the goal name, the target amount, the amount saved so far, and the amount still to go. Then say how many regular contributions are left at the current pace, if that is known.

## Don't

- Don't list individual transactions.
- Don't answer for spending totals.
- Don't move money or change the goal.
