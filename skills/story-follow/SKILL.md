# Story follow

Use the Get Story Updates tool to check the story the user is following.

If there is a new development since the last check, say what changed and when it happened, in one short paragraph. If the story has ended or gone quiet for a day, say so and stop following it unless the user asks to keep watching.

If nothing has changed, say so in one short line and stop.

Do not add other stories. Do not summarise the whole story again.
