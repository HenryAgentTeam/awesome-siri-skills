# Split an Expense

1. Find everyone involved. If the user named a group, use the Find Groups tool. Otherwise use the Find Contacts tool for each name. If a name matches more than one person, ask which one.
2. Split evenly unless the user gave amounts or shares. If they said "I paid", the user is the payer. If they didn't say who paid, ask.
3. Use the Add Expense tool with the total, the payer, and each person's share. Use the currency the user said, or the group's default currency.

## Don't

- Don't round shares so they no longer add up to the total.
- Don't add people who weren't mentioned, even if they are in the group.
