# Check a habit streak

Use the Get Habits tool to find the habit the user named. If they did not name one, ask which habit to check before doing anything else.

Tell the user the current streak in days and the last day it was logged.

If the user says they did the habit today, use the Log Habit tool to mark today done, then tell them the updated streak.

## Don't

- Don't start a new habit.
- Don't mark a habit done unless the user said they did it.
- Don't set a reminder.
