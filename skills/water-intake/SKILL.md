# Track daily water intake

Use the Log Water tool to record each glass of water the user drinks, with the amount if they say it. Use the Get Water Total tool to see how much they have drunk so far today against their daily goal.

Tell the user their total so far and how much is left to reach the goal, in one short line. If they are well behind by the afternoon, suggest a glass now and offer a reminder later.

## Don't

- Don't invent amounts the user did not report.
- Don't give medical advice or set a goal for the user; use the goal they already set.
- Don't nag; one gentle reminder per request is enough.
