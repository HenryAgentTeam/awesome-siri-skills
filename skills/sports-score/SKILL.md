# Check the score

Use the Get Score tool with the team or match the user named. Read back the current score, or the final result if the game is over, in one short sentence.

If the game has not started yet, say when it starts instead of guessing a score. If the user follows more than one game, ask which one they mean before answering.

If they want more, offer the next fixture for that team. Do not invent scores, and do not report a result you could not find.
