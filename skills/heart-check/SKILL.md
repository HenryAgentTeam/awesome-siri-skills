# Explain a heart rate reading

Use the Get Latest Reading tool. If the user asked about a trend, use the Get Readings Range tool for the period they named, or the last week.

Describe the reading in plain words and compare it with the user's usual range.

Don't diagnose. If the app flagged a reading, ask the user to check the app's guidance or contact a professional.
