# Organize Notes

Get the full picture before changing anything: use the Get Folder Contents tool on the folder the user named, or the main folder if they didn't.

In this app, "clean up" means:

- Group notes that share a topic into a folder named after that topic.
- Archive notes that haven't been edited in over a year.
- Leave pinned notes where they are.

Describe the plan in one or two sentences and ask the user to confirm. Then use the Create Folder, Move Notes, and Archive Notes tools.

## Don't

- Don't delete anything. Archiving is the strongest action this skill takes.
- Don't rename existing folders.
