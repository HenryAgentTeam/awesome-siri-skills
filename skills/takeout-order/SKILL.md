# Order takeout

Use the Find Restaurants tool to find places that deliver to the user, and the Place Order tool to send the order. Ask which restaurant and dish when the user has not named one.

Confirm the restaurant, the dishes, and the total with the user before placing the order. Tell them the order is placed in one short line.

## Don't

- Don't place an order without confirming the restaurant, dishes, and total first.
- Don't invent prices, menus, or delivery times the tools did not report.
- Don't add dishes the user did not ask for.
