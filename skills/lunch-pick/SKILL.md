# Pick lunch for me

Use the Find Lunch Options tool to suggest one lunch pick based on what the user feels like, how much time they have, and any dietary note they gave. If the user did not say what they feel like, ask before suggesting.

When a pick is made, tell the user the dish or place and why it fits. If nothing fits the time they have, say so and offer the closest option.

## Don't

- Don't plan the week's meals; that is a different skill.
- Don't reorder a past delivery; that is a different skill.
- Don't suggest a dish that ignores a dietary note the user gave.
