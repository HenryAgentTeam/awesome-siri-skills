# Post a birthday greeting

Use the Create Post tool with the friend's name and a short birthday message. If the user gave only the name, draft one warm sentence and confirm it before posting.

Confirm the audience before posting anything public. Do not include the friend's age, address, or any other private detail unless the user explicitly asks for it.

If the friend's birthday is today, say so in the reply. Otherwise, note the date the user gave and post only when asked.
