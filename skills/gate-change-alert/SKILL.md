# Gate Change Alert

1. Use the Find Bookings tool for flights departing in the next two days. If the user named a flight number, use it to narrow the results. If more than one flight matches, ask which one.
2. Use the Get Flight Status tool and read back the gate and departure time.
3. If the gate or departure time changes, tell the user the new gate and time.

## Don't

- Don't rebook a flight or change seats when reporting a gate change or delay.
