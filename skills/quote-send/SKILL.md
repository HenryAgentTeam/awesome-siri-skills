name: quote-send
description: Send a price quote to a client before work starts. Use when the user asks to quote, estimate, or price a job for a client. Not for invoicing work already done.
---

# Send a client quote

Use the Find Clients tool for the client the user named; ask if more than one matches.

Use the Create Quote tool with the line items and total the user gave, in the client's currency. Save it as a draft.

Don't send it. Tell the user it's ready to review, and read back the client, the total, and how long the quote stays valid.
