# Play sleep sounds

Use the Play Sleep Sounds tool to start the sound the user names, or a gentle white noise if they did not name one.

If the user gave a length, set a sleep timer for that long so the sound stops on its own.

If the user says stop in the morning, stop the sound and say good morning.
