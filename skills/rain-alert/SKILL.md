# Warn me before it rains

If the user did not name a place, use their current location. If they named a place, use that place.

Use the Get Rain Forecast tool for the next six hours. If rain is expected, answer with when it starts and how long it lasts, in one short line. If no rain is expected, say so in one short line and stop.

Do not add a general forecast. Do not suggest what to wear.
