# Tell me when the price drops

Use the Get Saved Items tool to find the item the user wants to watch, and the Check Price tool to read its current price. If the user named a target price, watch for the price to fall to that target or below it. If they did not name one, ask what target to watch for before setting the watch.

When the price reaches the target, tell the user the item, the new price, and the target it crossed. Do not place an order or add the item to a cart.

## Don't

- Don't watch an item the user did not name.
- Don't report a price change that is not a drop below the target.
- Don't buy anything when the price drops.
