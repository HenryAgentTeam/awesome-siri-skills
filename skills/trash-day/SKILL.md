# Never miss bin day

When the user asks about bins, trash, or recycling, check the household bin schedule first with the Check Bin Schedule tool.

If tomorrow is a pickup day, use the Set Reminder tool for tonight, naming which bin goes out and what time to put it out. If tomorrow is not a pickup day, just say when the next pickup is and which bin it is.

If the schedule is not set up yet, say so plainly and ask the user to add the pickup days first. Do not guess the schedule.

Answer with one short line. If a reminder was set, say when it will fire.
