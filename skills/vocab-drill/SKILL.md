# Drill vocabulary words

Use the Start Vocabulary Quiz tool with the word list and round length the user gave, and ask one word at a time.

Keep score as the round goes on, and repeat the words the user missed at the end.

If the user did not name a word list, ask which one to use instead of guessing.
