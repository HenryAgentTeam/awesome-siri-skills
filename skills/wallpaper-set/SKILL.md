# Set a photo as wallpaper

Use the Get Photos tool to find the photo the user named. If they did not name one, ask which photo to use before doing anything else.

Use the Set Wallpaper tool to set that photo as the wallpaper. If the user said lock screen or home screen, set it there. If they did not say, ask which screen to use.

Tell the user the photo is set and on which screen.

## Don't

- Don't crop or edit the photo.
- Don't set a photo the user did not choose.
- Don't make a slideshow or an album.
