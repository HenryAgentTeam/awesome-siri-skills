# Compare prices for this

Use the Compare Prices tool to check the price of the item the user named at each store that sells it. If the user did not name an item, ask which item they want compared before searching.

Report the cheapest option first, then the other prices in one short list. If prices differ only by delivery or pickup, say so. If no store carries the item, say so plainly and do not invent a price.

## Don't

- Don't invent a price, a store, or a discount that was not returned.
- Don't place an order or apply a coupon; that is a different skill.
- Don't watch a price over time; that is a different skill.
