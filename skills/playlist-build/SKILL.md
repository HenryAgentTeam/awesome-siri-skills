# Build a playlist

Use the Get Library tool first and prefer songs the user already likes. Use the Search Songs tool to fill gaps.

Aim for about 25 songs unless the user gave a length. Name the playlist after what they asked for.

Use the Create Playlist tool, then offer to play it.
