# Meeting notes summary

Use the Summarize Meeting tool for the meeting the user names, or the most recent one if they give no name. Keep the notes short: what was decided, what is still open, and who owns each follow-up.

Read back no more than five decisions and five next steps, each in one short sentence. If the meeting has no clear decisions, say so plainly instead of inventing any.

If the user asks for the full notes, use the Get Meeting Notes tool for that meeting and read them back in full.
