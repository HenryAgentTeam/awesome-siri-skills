# Answer the doorbell

1. Use the Show Doorbell Camera tool to show who is at the door.
2. Tell the user who it is. If the visitor is expected, say so; if not, ask whether to talk to them.
3. Use the Talk to Visitor tool to speak with them, or leave a message if the user prefers not to talk.

## Don't

- Don't unlock the door. Answering is not unlocking.
- Don't open the door for a stranger without asking the user first.
