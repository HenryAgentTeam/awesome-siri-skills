# Take a short stretch break

Use the Start Stretch Break tool to guide a short stretch break of two or three gentle stretches, lasting no more than five minutes. Pick stretches that suit sitting at a desk, and say how long to hold each one.

If the user reports pain, stop the stretch and suggest resting instead of pushing through it.

## Don't

- Don't log a workout; that is a different skill.
- Don't start a sleep wind-down; that is a different skill.
- Don't suggest stretches that need floor space or equipment the user did not mention.
