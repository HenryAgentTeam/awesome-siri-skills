# Host a trivia night

Use the Ask Question tool to ask the next quiz question.

Use the Keep Score tool to record each correct answer and keep the score.

If the user asks for an easier round, ask simpler questions. If they ask for a harder round, ask tougher ones.

When the game ends, announce the winner and the final scores.
