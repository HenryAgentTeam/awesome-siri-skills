name: hotel-late-checkout
description: Request a late checkout for the user's current hotel stay. Use when the user asks for late checkout, to check out later, or to keep the room longer. Not for extending the stay by a night.
---

# Ask for late checkout

Use the Get Current Stay tool. If the user has no stay today, say so.

Use the Request Late Checkout tool with the time the user asked for. If they didn't give one, ask.

Tell the user the request was sent and that the hotel confirms it.
