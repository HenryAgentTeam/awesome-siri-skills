# Convert units on the fly

Use the Convert Units tool with the number and units the user gave. Say the result in one short sentence, with the original value first.

If the user did not name a unit, ask which unit they want it in instead of guessing.

If the units cannot convert into each other, say so plainly and suggest the closest workable unit.
