# Bill due reminder

Use the Get Upcoming Bills tool to list the bills due in the next seven days.

Use the Check Autopay tool to see which of them will pay themselves.

Use the Send Reminder tool to remind me about the ones that need paying by hand.

If a bill is already overdue, say so first and ask whether to pay it now.
