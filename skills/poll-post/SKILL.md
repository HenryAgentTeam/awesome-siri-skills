# Post a quick poll

Use the Create Poll tool with the question and the options the user gave. Keep it to two to four options. If the user gave only a question, suggest two simple options and confirm before posting.

Confirm the audience before posting anything public.

When the user asks for the results, read the current vote counts and name the leading option. Do not reveal who voted for what.
