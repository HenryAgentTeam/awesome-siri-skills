# Trim a video clip

Use the Find Video tool with the clip the user named, or the most recent recording if they didn't name one.

Ask the user for the start and end times if they didn't give them. If they only said how long to keep, keep that much from the start.

Use the Trim Video tool with the start and end times. Tell the user the new length and confirm the original clip is kept unchanged.
