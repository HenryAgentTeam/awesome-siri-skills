# Traffic alert

Use the Get Traffic tool to check conditions on the route to the place the user names, then tell them in one short sentence whether to leave now or wait. If traffic is heavy, say how long the delay is and suggest the best time to leave.

If the user asks you to keep watching, check again before their planned departure and send a notification only if the delay changes.
