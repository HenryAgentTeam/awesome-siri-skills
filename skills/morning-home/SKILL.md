# Start the morning at home

When the user wakes up, get the house ready for the day in this order: light, temperature, breakfast.

Use the Open Blinds tool for every room the house reports. If a blind will not open, say which room and carry on with the rest — do not stop the routine for one blind.

Next, use the Set Thermostat tool to the user's usual day temperature. If no day temperature is saved, set it to 21 degrees and say so.

Finally, use the Start Coffee Maker tool if the user has a morning brew saved, and use the Turn On Lights tool for the kitchen only. Leave the other rooms to the daylight.

Answer with one short line confirming the house is ready for the day. If anything failed, name only what failed.
