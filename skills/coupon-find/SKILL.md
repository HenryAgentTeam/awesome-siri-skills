# Find me a coupon for this

Use the Find Coupons tool to look for a coupon or discount for the item the user named. If the user did not name an item, ask which item they want a coupon for before searching.

When a coupon is found, tell the user the item, the discount, and any terms that limit how it can be used. If no coupon is found, say so plainly and do not invent a code or a discount.

## Don't

- Don't invent a coupon code or a discount that was not returned.
- Don't apply a coupon or place an order.
- Don't watch a price over time; that is a different skill.
