# Breaking news

1. Use the Get Breaking News tool to fetch the newest stories.
2. Read out only stories from the last few hours, newest first.
3. If nothing new has broken since the user last asked, say so plainly instead of repeating older news.

## Don't

- Don't present opinion pieces or analysis as breaking news.
- Don't repeat yesterday's stories as if they just happened.
