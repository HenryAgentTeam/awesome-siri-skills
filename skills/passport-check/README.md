## Why this works

**It encodes the six-month rule.** Many destinations require a passport to stay valid for six months after travel, so the skill compares the expiry date against the trip's return date instead of just reading the date back.

**It stays in its lane.** Expiry is not a visa requirement, so the skill says so and does not give visa advice.
