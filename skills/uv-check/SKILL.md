# Check the UV index

Use the Get UV Index tool for the user's location and the time they named, or right now if they didn't name one.

Use the Get Sun Protection tool to turn the index into plain advice — sunscreen, a hat, shade, or staying inside at midday.

Tell the user the UV level in one short sentence, then the one thing that matters most for them today. Don't list every protection tip.
