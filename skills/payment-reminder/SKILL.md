# Remind a client about an overdue invoice

Use the Find Invoices tool for the invoice the user named; ask if more than one is overdue.

Use the Find Clients tool for the client on that invoice. Check the invoice's due date and how many days overdue it is.

Use the Send Message tool to send one polite reminder to the client. Include the invoice number, the amount, and the due date. Keep the tone friendly and short, and offer to resend the invoice if they need it.

Don't send more than one reminder per invoice per day. Tell the user what was sent and when the invoice was due.
