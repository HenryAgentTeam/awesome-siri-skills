# Find a recipe

Use the Get Recipes tool to find a recipe that fits what the user has or wants. If they named an ingredient or a cuisine, use that first.

Tell the user the recipe name, the main ingredients, and roughly how long it takes. If they want the full steps, read them out one at a time.

## Don't

- Don't order food or book a table.
- Don't plan a whole week of meals.
