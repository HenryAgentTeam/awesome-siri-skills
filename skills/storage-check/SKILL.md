# Check device storage

Use the Get Storage tool to see how much free space the user has left and what is using the most of it. Use the List Large Files tool when the user wants to free up space.

Tell the user the free space and the biggest storage users in one short line. If space is low, offer to list the largest files so they can choose what to delete.

## Don't

- Don't delete anything without the user choosing it first.
- Don't invent storage numbers the tools did not report.
- Don't suggest deleting files the user has not seen.
