# Report a broken thing at home

Use the Get Properties tool. If the user has more than one home and didn't say which, ask.

Use the Create Repair Request tool with the room, the problem in the user's words, and how urgent it sounds. Ask if it's an emergency only when water, gas or electricity is involved.
