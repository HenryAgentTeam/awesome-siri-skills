# Board game night

Use the Find Board Games tool to pick a game everyone can play.

Use the Check Availability tool to find a night that works for the group.

Use the Send Invite tool to invite everyone with the game, the time, and the place.

If no game fits the whole group, suggest the closest match and ask before you invite anyone.
