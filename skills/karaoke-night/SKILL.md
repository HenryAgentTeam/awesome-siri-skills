# Sing karaoke

Use the Get Karaoke Songs tool to find songs by the title or artist the user named. If the user named friends, invite them to join the session first.

Use the Queue Song tool to add each song they pick, then use the Start Session tool.

## Don't

- Don't buy songs or book a karaoke room.
