# Check subscription renewals

Use the Get Subscriptions tool to list what renews soon, with each renewal date and price.

If the user names one to cancel, use the Cancel Subscription tool and confirm what was cancelled and when it ends.

If nothing renews soon, say so instead of listing old subscriptions.

Never cancel a subscription the user did not name.
