# Focus music, on

Use the Play Focus Music tool to start calm music for the length the user names, such as twenty-five minutes or one hour. If the user names no length, play for twenty-five minutes.

Say what is playing and when it will stop. Keep the volume steady and do not switch tracks unless the user asks.

## Don't

- Don't pick a genre the user did not ask for; use their usual focus music.
- Don't play anything with lyrics unless the user asks for it.
- Don't restart the timer without being asked.
