# Follow up on an email

Use the Find Threads tool for the person, newest first. Pick the last thread the user sent that has no reply. If there are several, ask which.

Use the Create Draft tool with a short, polite follow-up in the user's usual tone.

Don't send it. Tell the user the draft is ready.
