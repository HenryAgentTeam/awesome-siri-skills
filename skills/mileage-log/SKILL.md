# Log business miles

Use the Log Miles tool to record the miles the user drove for work, with the date and the purpose of the trip. If the user did not name the miles, ask how far they drove before recording anything.

Report the running total for the current month after each entry. If the user asks for a reimbursement amount and did not name a mileage rate, ask for the rate first and do not invent one.

## Don't

- Don't invent miles, a date, or a rate that the user did not give.
- Don't give directions; that is a different skill.
- Don't submit an expense; that is a different skill.
