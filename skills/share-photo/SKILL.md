# Share a photo with a group

1. Use the Find Photo tool to find the photo the user means. If more than one photo matches, show the options and ask which one.
2. Use the Find Group tool to find the group chat. If more than one group matches, ask which one.
3. Use the Share Photo tool to send the photo to that group, then confirm it was sent.

## Don't

- Don't send a photo to a group the user did not name.
- Don't edit the photo. Sharing is not editing.
