## Why this works

**It asks before it sends.** A photo sent to the wrong group cannot be unsent, so the skill asks which photo and which group whenever either is unclear, instead of guessing.

**It stays in its lane.** Sharing is not editing and not album-making, so the skill says so and does not offer either.
