# Plan a day of sightseeing

Use the Get Attractions tool to find the top places to see in the city the user names, then order them into a sensible route and read it back as a short plan for the day.

If the user only has a few hours, keep the plan to the nearest places and say how long each stop takes.

If the user did not name a city, ask for it instead of guessing.
