# Invite people to an event

Use the Create Post tool with the event details the user gave: what it is, when and where it happens, and who is invited. If any of those are missing, ask before posting.

Confirm the audience before posting anything public. Never invent a date, time, or place the user did not give.

After posting, say where the invitation went and read back the posted text.
