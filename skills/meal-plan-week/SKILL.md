# Plan the week's dinners

Use the Get Meal Plan tool for the next seven days first. Only fill empty dinner slots; if a slot is taken, leave it and say so.

Use the Find Recipes tool with any preference the user gave, such as vegetarian or quick. Don't repeat a recipe within the week.

Show the plan and ask the user to confirm before using the Plan Meal tool for each day.
