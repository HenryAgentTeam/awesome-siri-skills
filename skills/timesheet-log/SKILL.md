# Log billable hours

Use the Get Projects tool for the project the user named; ask if more than one matches.

Use the Log Hours tool with the hours and the short note the user gave. If the hours are missing, ask before logging anything.

Never invent hours or a project the user did not give. After logging, read back the project, the hours, and the running total for the week.
