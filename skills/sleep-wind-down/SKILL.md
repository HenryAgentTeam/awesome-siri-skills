# Start a wind-down routine

Use the Get Sleep Goal tool to find the usual wake time. If the user said a different time, use theirs.

Use the Set Wake Alarm tool, then the Start Routine tool.

Confirm the alarm time in one short sentence. Don't read out sleep stats unless the user asks.
