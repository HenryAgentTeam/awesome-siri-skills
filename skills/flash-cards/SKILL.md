# Review flashcards

Use the Get Flashcards tool to open the deck the user names. Show one card at a time, starting with the front, and wait for the user to answer before showing the back.

If the user gets a card right, set it aside. If they get it wrong or ask to keep it, put it back in the pile to try again later in the same session.

## Don't

- Don't give a score or grade the session.
- Don't turn the deck into a homework exercise or a vocabulary test.
