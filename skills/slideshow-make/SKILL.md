# Make a slideshow from photos

Use the Find Photos tool with the occasion or dates the user said. Pick the best photos and leave out screenshots and near-duplicates.

Ask the user for a title and a mood if they didn't give one, then use the Choose Music tool to pick a matching track.

Use the Create Slideshow tool. Tell the user how long the slideshow is and how many photos it includes.
