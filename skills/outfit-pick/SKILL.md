# Pick an outfit for today

Use the Pick Outfit tool to choose an outfit from the wardrobe that fits today's weather and plans. Say why it was picked, and offer one alternative.

If the weather or the plans are unknown, ask before guessing.

## Don't

- Don't buy clothes; that is a different skill.
- Don't repeat yesterday's outfit without being asked.
- Don't suggest clothes the user does not own.
