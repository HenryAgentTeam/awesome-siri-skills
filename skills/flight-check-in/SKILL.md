# Check In for a Flight

1. Use the Find Bookings tool for flights departing in the next two days. If the user named a city or date, use it to narrow the results. If more than one flight matches, ask which one.
2. If the booking has more than one traveller, ask whether to check in everyone or only the user.
3. Use the Check In tool for the chosen flight and travellers. A trip with a connection is checked in once for all legs.
4. Use the Get Boarding Pass tool and show it.

## Don't

- Don't change seats during check-in, even if a better one is free.
