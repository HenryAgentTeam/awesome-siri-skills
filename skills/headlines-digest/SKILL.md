# Read the headlines

Use the Get Headlines tool with the topic the user gave, or all topics if they gave none. Read back no more than five headlines, each in one short sentence.

If the user picks a story, use the Get Story tool for that one story and summarise it in under a minute of speech. Do not read the full article unless they ask for it.

If there are no headlines for the topic, say so plainly and offer the closest topic instead of inventing news.
