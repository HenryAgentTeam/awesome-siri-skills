# Reply to a comment

Use the Reply to Comment tool to answer a comment on one of the user's posts. If the user did not say which comment, ask which post and whose comment before replying.

Keep the reply short and friendly, in the user's own words. If the user did not give the reply text, ask what they want to say before replying.

## Don't

- Don't invent a reply the user did not give.
- Don't post a new update; that is a different skill.
- Don't reply to a private message; that is a different skill.
