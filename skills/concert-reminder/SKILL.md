# Upcoming concert

Use the Get Concerts tool to find upcoming concerts by the artists the user follows. If they named an artist, check that artist first.

Tell the user the artist, date, venue, and city for the next concert. If nothing is coming up, say so and offer to check again later.

## Don't

- Don't buy tickets or book travel.
