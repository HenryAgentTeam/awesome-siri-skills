# Submit an expense

Use the Get Expenses tool to find the expense the user named. If they did not name one, ask which expense to submit before doing anything else.

Confirm the amount and the receipt with the user, then use the Submit Expense tool to file it for approval. Tell the user it was submitted and who approves it.

## Don't

- Don't submit an expense the user did not confirm.
- Don't check approval status.
- Don't reimburse anyone.
