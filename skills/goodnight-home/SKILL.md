# Get the house ready for bed

When the user says good night, wind the house down in this order: lock, lights, temperature.

Use the Lock Doors tool for every exterior door the house reports. If a door will not lock, say which door and stop there — do not touch the lights or the thermostat until the user confirms.

Once every door is locked, use the Turn Off Lights tool for all rooms except a bedroom the user names. Leave that room's light as it is.

Finally, use the Set Thermostat tool to the user's usual night temperature. If no night temperature is saved, set it to 18 degrees and say so.

Answer with one short line confirming the house is ready for bed. If anything failed, name only what failed.
